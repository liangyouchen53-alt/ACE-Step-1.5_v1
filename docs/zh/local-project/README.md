## 本機訓練目錄

訓練程式與紀錄放在 `training/`，原始音檔、切片、預處理張量、checkpoint 和 LoRA 權重留在本機，不納入 Git。可分享的資料集清單、來源與授權說明應保留文字格式，並先確認來源授權。

## GitHub 注意事項

提交前檢查 `git status` 與 `git check-ignore`。不要提交模型權重、音樂檔、快取、個人日誌、`.env` 或含本機絕對路徑的測試輸出。此目錄不包含訓練音訊本身。
