# 訓練資料與模型目錄

所有路徑均相對於專案根目錄 `ACE-Step-1.5/`。

| 路徑 | 用途 | Git 狀態 |
|---|---|---|
| `training/piano_pilot/` | 小型鋼琴 LoRA 流程與紀錄 | 保留腳本與文件；音訊、張量、權重忽略 |
| `training/piano_expanded/` | 擴增鋼琴資料及實驗紀錄 | 同上 |
| `training/downloaded_piano/` | Open Goldberg 下載素材與授權清單 | 音訊忽略；來源及文件按檔案大小與授權檢視 |
| `training/my_piano/` | 使用者鋼琴模型 | 權重、張量、音訊忽略 |
| `training/singing_bowl/` | 頌缽初版資料流程 | 音訊、張量、權重忽略 |
| `training/singing_bowl_expanded/` | 擴充頌缽候選資料與生成比較 | 音訊、張量、權重忽略 |
| `training/singing_bowl_manual/` | 使用者手動下載音檔的切片與張量 | 原始下載、切片、張量、權重忽略；保留腳本與說明 |
| `training/singing_bowl_new_sources/` | 手動下載來源檔暫存處 | 整個 `manual/` 音檔目錄忽略 |

訓練 manifest 中的音訊路徑指向本機檔案，因此克隆 Git 倉庫本身不會包含可立即訓練的完整資料集。要重現訓練，需依來源清單取得授權素材並重新執行預處理。未確認授權的音檔不應公開散布。

## 常見資料流程

1. 將原始來源放入對應 `raw/` 或 `training/singing_bowl_new_sources/manual/`。
2. 執行該資料集目錄內的 `prepare.py`，產生切片、JSON manifest 和來源雜湊。
3. 執行 `run.ps1 -Action preprocess`，產生本機 tensors。
4. 檢查 `verification.json` 後再執行 `run.ps1 -Action train -Epochs 4`。
5. LoRA 和訓練中間資料保留在本機；確認品質後，再決定是否另行發布模型。

各資料夾的實際參數以同目錄 `開始訓練.md`、`run.ps1` 和 `preparation.json` 為準。
