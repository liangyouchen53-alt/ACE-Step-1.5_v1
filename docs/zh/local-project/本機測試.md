# ACE-Step 1.5 本機測試

## 啟動中文介面

雙擊 `start_local_5060.bat`，啟動後開啟 http://127.0.0.1:7860 。
只綁定本機位址；關閉啟動視窗可停止服務。

## 初期生成設定

- 模型：acestep-v15-turbo（2B）
- 網站啟動時初始化 5Hz LM 1.7B，後端為 pt，支援簡易生成與描述整理。若只使用自訂描述生成，可關閉 Thinking 以節省時間。
- Instrumental 開啟，Lyrics 填 `[Instrumental]`。
- Duration：30 秒；Batch size：1；Steps：8；Shift：3。
- CPU offload 與 DiT offload 開啟。
- 初期關閉編譯、Flash Attention 與量化，先驗證基本生成。

範例描述：
Instrumental ambient piano music, gentle warm piano, soft strings, calm mood, sparse arrangement, no vocals, no humming, no choir, no speech.

## 重跑固定種子測試

在此資料夾開啟 PowerShell 執行：

```powershell
.\.venv\Scripts\python.exe -X utf8 local_smoke_test.py
```

輸出音檔及 test_result.json 位於 `outputs/local_smoke_test/`。
此腳本不執行微調，也沒有載入 LoRA。

## 環境

使用資料夾內的 Python 3.11 與 .venv，不使用系統 Python 3.14。
模型位於 checkpoints。後續 LoRA 請配合訓練時相同的基礎模型使用。

## 網頁功能範圍

本機啟動檔啟用 ACESTEP_GENERATION_ONLY=true。網頁只建立音樂生成與「我的音樂」頁籤，不建立訓練頁籤、資料集介面及訓練事件。訓練 CLI 仍保留。
「我的音樂」可重新整理、試聽、下載音檔和 JSON 參數，或在檔案總管開啟 gradio_outputs。
清單預設顯示「一般生成音樂」，可切換「模型測試音樂」或「全部音樂」。目前兩組模型比較資料夾與已知的鋼琴設定測試音檔歸入測試類；未來驗證音檔請存於 gradio_outputs/model_tests。
切換分類會同步試聽與刪除清單，並清除舊勾選和刪除確認。分類僅影響顯示，不移動音檔或改變報告中的音訊路徑。
「一鍵清空目前分類」會將該分類的全部音樂及未共用的生成資料移至 Windows 資源回收筒，不需逐首勾選。選「全部音樂」時範圍包含一般與測試音樂；刪錯可至資源回收筒還原，清空資源回收筒後才會釋放空間。原有勾選永久刪除功能仍保留。
一鍵清空也會整理輸出資料夾內的空子資料夾。選「全部音樂」時會將 gradio_outputs 內所有檔案與子資料夾移至資源回收筒，包含殘留的生成資料；保留 gradio_outputs 本身。清空測試音樂後，報告中的對應音訊連結會失效。


## 獨立訓練工具

雙擊 TRAIN_PIANO.bat 可開啟繁體中文訓練選單。詳見 training/piano_pilot/獨立訓練操作手冊.md。網頁仍只提供生成與音樂瀏覽；訓練在終端機進行，且會先停止網站。


「我的音樂」的「清理音樂」可勾選多首並永久刪除。需另外勾選確認，音檔與未被其他格式共用的 JSON/LRC/VTT 會刪除，操作無法復原；不會刪除訓練資料或模型權重。

## 平靜鋼琴生成設定

重新整理網站，切至 Custom（自訂），展開「🎹 平靜鋼琴生成設定」，按「套用 30 秒平靜鋼琴設定」，再生成。
適用本機 Turbo 模型：30 秒、65 BPM、批次 1、8 步、shift 3、FLAC 無損輸出、峰值 -1 dB 與 1.5 秒淡出。
使用明確英文獨奏描述，關閉 Think 與 LM 改寫；保留已安裝的 1.7B LM 供其他模式使用。清除參考音訊及音訊代碼，避免舊素材影響本次生成。
此按鈕會取代提示詞與上述參數，但不修改模型權重、不自動啟用 LoRA。原模型比較請關閉 LoRA。
FLAC 避免額外有損壓縮，淡出能改善突然截斷，但無法保證樂句結束、樂器完全正確或旋律品質。多個種子的結果仍需試聽挑選。
實測產生 30 秒、48 kHz、雙聲道 FLAC；數值有效、峰值低於 0 dBFS、尾端歸零。技術檢查不代表已證明主觀品質提升。
