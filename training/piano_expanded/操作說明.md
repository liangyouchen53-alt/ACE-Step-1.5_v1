# 擴充版純鋼琴訓練

在 ACE-Step-1.5 資料夾開啟 PowerShell。模型、程式及資料下載後，訓練、評估與生成不需要 GPT 額度，也不需要 OpenAI API。

依序執行：

```powershell
powershell -ExecutionPolicy Bypass -File training/piano_expanded/run.ps1 -Action prepare
powershell -ExecutionPolicy Bypass -File training/piano_expanded/run.ps1 -Action preprocess
powershell -ExecutionPolicy Bypass -File training/piano_expanded/run.ps1 -Action train
powershell -ExecutionPolicy Bypass -File training/piano_expanded/run.ps1 -Action evaluate
powershell -ExecutionPolicy Bypass -File training/piano_expanded/run.ps1 -Action compare
```

prepare 需要網路，其他步驟使用本機模型與資料。preprocess、train、evaluate、compare 會關閉本專案的 7860 網站以釋放 GPU 記憶體。完成後雙擊 start_local_5060.bat 恢復網站。電腦必須保持運作，不能休眠。

新版模型：`training/piano_expanded/lora/final`。舊版模型保留在 `training/piano_pilot/lora/final`。
網站的 LoRA 欄位可載入新版資料夾進行試聽；初始比較使用強度 1.0。不要在未比較前直接宣稱新版較佳。

預設為全新 rank 8 / alpha 16 LoRA、6 epochs、學習率 0.00005、批次 1、梯度累積 4、Adafactor、bf16、梯度檢查點與 CPU offload。它從原始 Turbo 模型另開新訓練，不覆寫先前 LoRA，也不更新 1.7B LM。

若已存在 final 權重，train 會拒絕覆寫。要重做不同實驗，先用不同資料夾保存整套設定、資料清單與權重。續訓需使用 `lora/checkpoints/epoch_*` 下含 optimizer/scheduler 狀態的檢查點，不能只拿 final 權重宣稱是完整續訓。

評估檔案：`evaluation.json` 是固定噪聲與時間步的保留資料 flow MSE；`comparison.json` 保存相同兩個種子下三種模型的音檔路徑與技術指標。MSE 降低不等於人類聽感提升。評估曲目不可加入訓練；日後若依評估結果調參，需再留一組全新的最終測試曲目。

compare 完成後會產生「試聽比較.html」與「試聽評分.csv」。用瀏覽器開啟 HTML，在相同音量下聽完並填寫 CSV，再揭曉各模型名稱。重跑 compare 會重新建立空白評分表；已填寫的評分請先另存一份。

本版含非商業資料；來源與引用詳見 DATA_LICENSE.md、sources.json。產出權重不應被當成已取得商業授權的模型。
