# 不需要 GPT 的純鋼琴 LoRA 獨立訓練操作手冊

本手冊與本機腳本不依賴 ChatGPT、GPT API 或付費模型額度。資料與套件備妥後，預處理、訓練、續訓、生成比較音檔都能離線執行；首次下載資料與安裝套件才需要網路。電腦仍需開機、避免睡眠，且要有可用磁碟空間。

## 最簡單的使用方式

在 ACE-Step-1.5 資料夾雙擊 `TRAIN_PIANO.bat`，會開啟繁體中文文字選單。

1. 選 1：下載範例錄音並切片。這一步有網路需求；已下載的錄音會重用。
2. 選 2：預處理。會自動停止本機音樂網站，釋放 GPU。
3. 選 3：輸入 4，開始這次相同的小規模訓練。
4. 完成後選 5：生成同提示、同種子的原模型／LoRA 比較音樂。
5. 選 8：重新啟動網站。在「我的音樂」重新整理清單，查看比較音檔。

如果本次試訓已經完成，可以直接選 5。不要為了重聽音樂再次從頭訓練。為避免覆蓋成果，選單 3 在已存在 final 權重時會停止：要延長訓練請選 4；要重新從頭訓練，先把 lora 資料夾改名保存。

## 本次試驗究竟訓練什麼

- 基礎模型：`checkpoints/acestep-v15-turbo`，2B 音樂 DiT。
- 方式：LoRA rank 8、alpha 16，只訓練小量附加權重，不改寫原始基礎模型。
- 不訓練 5Hz LM，所以不會修復 Simple 模式的中文理解問題。
- 訓練資料：3 場 MAESTRO 鋼琴演奏，每場切 8 段 10 秒，共 24 段。
- 保留資料：另一首不同曲目切 4 段，沒有送入訓練，也未計算正式驗證集 loss。
- 片段依非靜音、相對低 RMS 自動選取，尚非人工確認的放鬆音樂資料集。低音量不等於低情緒張力。
- 訓練設定：batch 1、梯度累積 4、4 epochs、學習率 0.00005、Adafactor、bf16、梯度檢查點、編碼器移至 CPU。
- 這是流程驗證，少量更新不足以證明音樂品質提升，也不保證完全無人聲。

原始錄音與片段來源見 `sources.json` 與 `clips.json`。資料授權為 CC BY-NC-SA 4.0，本次僅作非商業本機研究。請保留 `DATA_LICENSE.txt`；不得把這批資料當作已獲商業授權。基礎模型授權不會取代訓練資料授權。若要商用或發布模型，先另外確認權利與適用條件。

## 重要資料夾

| 路徑（相對於 ACE-Step-1.5） | 用途 |
|---|---|
| `training/piano_pilot/raw` | 下載的原始 WAV |
| `training/piano_pilot/clips/train` | 訓練短片段 |
| `training/piano_pilot/clips/heldout` | 不參與訓練的保留片段 |
| `training/piano_pilot/dataset.json` | 片段路徑、文字描述及純音樂標記 |
| `training/piano_pilot/tensors` | 已預處理的 `.pt` |
| `training/piano_pilot/lora` | 完成後的 LoRA 權重與每 epoch 檢查點 |
| `gradio_outputs/piano_pilot_comparison` | baseline／lora 比較音檔 |

不要任意改名基礎模型資料夾。搬到 5080 時也要使用相同基礎模型版本。

## 看見哪些檔案才算成功

訓練完成後，`lora/final` 應有：

- `adapter_model.safetensors`：LoRA 權重。
- `adapter_config.json`：LoRA 設定。
- `lora/checkpoints/epoch_...`：包含 `training_state.pt`，用於完整續訓；`final` 只有推理權重，不能完整恢復優化器狀態。

只看到日誌或 runs 資料夾，不代表已成功訓練。確認訓練日誌沒有 FAIL／CUDA out of memory，且權重存在；比較腳本也會實際載入它。

## 中斷後如何繼續

按 Ctrl+C 可要求停止。請等到程序結束；未完成的當前 batch 進度可能遺失。以最後成功存檔的 epoch 檢查點為準。

1. 用選單 6 查看權重位置，或在檔案總管搜尋 `training_state.pt`。
2. 選單 4 貼上該檔案所在的資料夾完整路徑。
3. 輸入更大的「總 epoch 目標」。例如已完成 4，輸入 8 表示繼續到第 8 個 epoch，不是再加 8。
4. 續訓時保持原資料、rank、alpha 與基礎模型不變。延長目標不保證學習率排程會自動重設；長期訓練前要檢查日誌中的實際 learning rate。

請不要載入網路上來源不明的 `training_state.pt`；只續用自己產生的檢查點。

## 自己換資料

推薦另建 `training/my_piano`，保存新資料、設定與輸出，避免覆蓋這次試驗。

1. 準備有使用權、無歌唱、無哼唱、無口語、無其他樂器的乾淨 WAV。
2. 先人工聽選安靜、慢速、低編曲密度的片段，再切成 10 秒。不要只調小音量冒充放鬆風格。
3. 用整首曲目分隔訓練與保留資料；同一首不同片段不要跨兩邊。
4. 仿照 `dataset.json` 建立標註；相對音檔路徑是相對於 JSON 所在位置。
5. 如實寫 caption，不知道 BPM、調性就留空；不要把所有曲子都標成 65 BPM。
6. 複製 `run.ps1` 並調整 `$taskData` 及預處理 JSON 路徑；保留 batch 1、rank 8 與 10 秒起點。
7. 新資料或新描述必須重新預處理；單改 epochs 不需要重新預處理。

最小樣本格式：

```json
{
  "audio_path": "clips/train/piano_001.wav",
  "caption": "Solo acoustic piano, gentle melody, quiet dynamics, no vocals.",
  "lyrics": "[Instrumental]",
  "is_instrumental": true,
  "duration": 10,
  "language": "unknown"
}
```

## 用 PowerShell 直接操作

在 ACE-Step-1.5 資料夾開啟 PowerShell：

```powershell
# 準備資料（只有這一步需要連網下載）
powershell -NoProfile -ExecutionPolicy Bypass -File .\training\piano_pilot\run.ps1 -Action prepare

# 生成訓練 tensors
powershell -NoProfile -ExecutionPolicy Bypass -File .\training\piano_pilot\run.ps1 -Action preprocess

# 小規模訓練
powershell -NoProfile -ExecutionPolicy Bypass -File .\training\piano_pilot\run.ps1 -Action train -Epochs 4

# 前後比較
powershell -NoProfile -ExecutionPolicy Bypass -File .\training\piano_pilot\run.ps1 -Action compare
```

不會永久更改電腦的 PowerShell 執行原則。

## 記憶體不足或速度太慢

- 先確認音樂網站真的停止，並關閉其他使用 GPU 的程式；關閉網頁分頁不等於停止服務。
- batch 維持 1；減少曲目數主要縮短時間，不會大幅降低每步顯示記憶體。
- 若 10 秒仍超出顯示記憶體，下一次縮成 5 秒並重新預處理；不要一開始增加片段長度與 rank。
- 如果 8GB 始終無法完成，就將這份資料、tensors、設定及相同基礎模型搬到 5080。
- 不要讓網站生成與訓練同時搶用 GPU。訓練時避免睡眠、重新啟動或拔電。
- 日誌在本資料夾的 `train-日期時間.log`、`preprocess.log`、`compare.log`；底層詳情也會寫到專案根目錄 `sidestep.log`。

## GPT 額度用完時

GPT 用量不會影響已下載的 ACE-Step 或訓練腳本。只要電腦開著，本機訓練不需要持續連線這個聊天，也不會消耗 GPT token。若電腦重開機或訓練停止，照「中斷後如何繼續」操作即可。這不是雲端訓練：關機後不會在背景繼續跑。


## 在網站使用這次 LoRA

本次成果在 `training/piano_pilot/lora/final`。開啟網站的設定區，找到 LoRA 載入控制，填入此資料夾的完整路徑，按載入並啟用，強度先用 1.0。基礎模型必須仍為 `acestep-v15-turbo`。這是載入權重進行生成，不是在網站上訓練。

網站重新啟動後不會自動套用這次試驗 LoRA，需要再次載入；這樣可保留原模型作比較。也可以直接使用選單 5，腳本會自動載入 LoRA 並生成前後比較，不必操作網站的進階設定。

## 本次已完成的結果

- 24 個 10 秒訓練片段，4 個保留片段，原曲來源不重疊。
- 已完成 4 epochs、24 次 optimizer 更新，並保存 4 份可續訓檢查點。
- 最終權重約 11.1MB，384 個 tensor 全部為有限值，192 組 LoRA B 權重均非零。
- 實際載入 LoRA 成功；原模型與 LoRA 均成功產生 30 秒、48kHz WAV。
- 檢查報告：`verification.json`；前後比較路徑：`comparison.json`。
- 這些結果證明流程可用，沒有證明比原模型更平靜、更好聽或完全沒有人聲；請先人工試聽。

環境的 Python、套件與模型都已放在本機。離線使用時不要重跑 uv sync，以免不必要地更新套件或重建中文路徑相關環境設定。若未來換電腦，需重新安裝相容環境，再搬移資料與模型。
